## 🌟 Επισκόπηση Έργου

Το **FuzzyTravel AI** είναι ένα προηγμένο έμπειρο σύστημα υποστήριξης αποφάσεων που παρέχει εξατομικευμένες τουριστικές προτάσεις συνδυάζοντας:
1. **Mamdani Fuzzy Inference System (FIS):** Μοντελοποίηση της ασάφειας στις ανθρώπινες προτιμήσεις (προϋπολογισμός, κλίμα, διάρκεια, δραστηριότητες) με τριγωνικές/τραπεζοειδείς συναρτήσεις συμμετοχής, 18 κανόνες εμπειρογνώμονα και αποσαφοποίηση κέντρου βάρους (Centroid Defuzzification).
2. **Fuzzy C-Means (FCM) Customer Profiling (Bezdek 1981):** Soft clustering που επιτρέπει σε έναν ταξιδιώτη να ανήκει μερικώς σε πολλαπλές τουριστικές περσόνες (π.χ. 65% Cultural Explorer, 25% Luxury Relaxer, 10% Backpacker).
3. **Multi-Criteria Scoring & Explainable AI (XAI):** Πολυκριτηριακή στάθμιση και διαφανής αιτιολόγηση προς τον ταξιδιωτικό πράκτορα για κάθε πρόταση.
4. **B2B Catalog Management:** Δυναμική διαχείριση αποθέματος προορισμών και τουριστικών πακέτων, έτοιμο για εμπορική αξιοποίηση.

## 🚀 Οδηγίες Εγκατάστασης & Εκτέλεσης

### 1. Ενεργοποίηση Εικονικού Περιβάλλοντος (Virtual Environment)
Στο macOS / Linux terminal:
```bash
source venv/bin/activate
```

*(Εναλλακτικά, αν δημιουργείτε νέο περιβάλλον)*:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Εκκίνηση της Εφαρμογής (Streamlit Dashboard)
```bash
streamlit run ui/app.py
```
Η εφαρμογή θα ανοίξει αυτόματα στον browser στη διεύθυνση:
👉 **`http://localhost:8501`**

## 🖥️ Περιγραφή Λειτουργιών Εφαρμογής

Η εφαρμογή διαθέτει 3 λειτουργίες μέσω του πλαϊνού μενού (Sidebar):

1. **✈️ Σύμβουλος Προτάσεων (Travel Agent Recommender):**
   * Εισαγωγή budget, κλίματος (°C), διάρκειας (ημέρες), ενδιαφερόντων (Πολιτισμός, Περιπέτεια, Χαλάρωση, Νυχτερινή Ζωή) και φίλτρου χώρας.
   * Αυτόματη ταξινόμηση στο κυρίαρχο FCM προφίλ και spider radar chart.
   * Προβολή των κορυφαίων 5 προορισμών με ποσοστό καταλληλότητας, εκτιμώμενο κόστος, προτεινόμενο πακέτο γραφείου και **Explainable AI bullet points**.
   * **📄 Εξαγωγή Επίσημης Ταξιδιωτικής Προσφοράς σε PDF (B2B Client Quotation):** Άμεση παραγωγή εξατομικευμένης επώνυμης προσφοράς για τον πελάτη με ανάλυση προφίλ, πακέτα, κόστη και αιτιολόγηση!
   * **🔄 Ανάδραση Χρήστη (Feedback Loop):** Δυνατότητα αξιολόγησης (1-5 αστέρια, αποδοχή/απόρριψη) με αυτόματη δυναμική επαναστάθμιση των μελλοντικών σκορ.
2. **🧠 Ασαφής Μηχανή & FCM (Ακαδημαϊκή Εποπτεία):**
   * Πλήρης οπτικοποίηση όλων των Συναρτήσεων Συμμετοχής με ένδειξη των τρεχουσών εισόδων.
   * Πίνακας των 18 κανόνων IF-THEN με ενεργά firing strengths $\alpha$.
   * Μαθηματικές μετρικές FCM (Partition Coefficient $PC$, Partition Entropy $PE$) και καμπύλη σύγκλισης $J_m$.
   * Πίνακας και analytics του Closed Feedback Loop.
3. **💼 Διαχείριση Καταλόγου & Πακέτων (B2B Inventory):**
   * Πλήρης βάση δεδομένων με **22 προορισμούς** (12 στην Ελλάδα: Σαντορίνη, Χανιά, Ζαγοροχώρια, Αθήνα, Μύκονος, Πήλιο, Μετέωρα, Κέρκυρα, Νάξος, Μάνη/Μονεμβασιά, Καστοριά, Ναύπλιο και 10 διεθνείς: Ρώμη, Παρίσι, Βιέννη, Ζερμάτ, Ρέικιαβικ, Μπαλί, Βαρκελώνη, Άμστερνταμ, Τόκιο, Νέα Υόρκη).
   * Φόρμα προσθήκης νέου προορισμού/πακέτου γραφείου σε πραγματικό χρόνο.
   * Εξαγωγή καταλόγου σε CSV.
