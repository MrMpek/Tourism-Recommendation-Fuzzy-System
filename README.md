## 🌟 Επισκόπηση Έργου

Το **FuzzyTravel AI** είναι ένα προηγμένο έμπειρο σύστημα υποστήριξης αποφάσεων που παρέχει εξατομικευμένες τουριστικές προτάσεις συνδυάζοντας:
1. **Mamdani Fuzzy Inference System (FIS):** Μοντελοποίηση της ασάφειας στις ανθρώπινες προτιμήσεις (προϋπολογισμός, κλίμα, διάρκεια, δραστηριότητες) με τριγωνικές/τραπεζοειδείς συναρτήσεις συμμετοχής, **36 κανόνες εμπειρογνώμονα** (πλήρης κάλυψη εισόδων με < 5% gap), συνόλα εξόδου (*Poor, Moderate, High, Excellent*) και αποσαφοποίηση κέντρου βάρους (Centroid Defuzzification).
2. **Fuzzy C-Means (FCM) Customer Profiling (Bezdek 1981):** Soft clustering που επιτρέπει σε έναν ταξιδιώτη να ανήκει μερικώς σε πολλαπλές τουριστικές περσόνες (*Cultural Explorer, Luxury Relaxer, Backpacker, Alpine Seeker, Cosmopolitan Nightlife*). Η ταυτοποίηση συστάδων επιτυγχάνεται με τον αλγόριθμο **Hungarian (Linear Sum Assignment)** εξασφαλίζοντας σταθερότητα ανεξαρτήτως τυχαιότητας αρχικοποίησης.
3. **FCM Persona-to-Archetype Influence (A1):** Το προφίλ του ταξιδιώτη τροφοδοτεί άμεσα το σκορ των προορισμών μέσω του πίνακα προτιμήσεων $W[j][\text{archetype}]$, υπολογίζοντας το `persona_score` (βάρος 15%) και το `persona_fit`.
4. **Fuzzy Scoring (B4):** Ασαφείς βαθμοί συμμετοχής για προϋπολογισμό (τραπεζοειδής συνάρτηση εντός budget) και κλίμα (τραπεζοειδής συνάρτηση ιδανικής θερμοκρασίας).
5. **Δυναμικός Βρόχος Ανάδρασης (Closed Feedback Loop):** Αυτόματη μάθηση και αναπροσαρμογή του σκορ προορισμών ($\Delta_{\text{feedback}}$) βάσει ιστορικών κριτικών και αποδοχών.
6. **Multi-Criteria Scoring & Explainable AI (XAI):** Διαφανής αιτιολόγηση προς τον πελάτη και τον ταξιδιωτικό σύμβουλο για κάθε πρόταση.
7. **B2B Catalog Management:** Δυναμική διαχείριση αποθέματος 22 προορισμών, εξαγωγή επίσημης προσφοράς σε PDF (B2B Quotation) και εξαγωγή σε CSV.

> ℹ️ **Σημείωση Δεδομένων:** Το ιστορικό σύνολο εκπαίδευσης του αλγορίθμου FCM αποτελείται από 350 συνθετικά δείγματα ταξιδιωτών (*Synthetic Behavioral Dataset*) που μοντελοποιούν ρεαλιστικά καταναλωτικά προφίλ στην Ελλάδα και διεθνώς.

## 🚀 Οδηγίες Εγκατάστασης & Εκτέλεσης

### 1. Εγκατάσταση Εικονικού Περιβάλλοντος (Setup)

#### Σε macOS / Linux:
```bash
# 1. Δημιουργία εικονικού περιβάλλοντος
python3 -m venv venv

# 2. Ενεργοποίηση
source venv/bin/activate

# 3. Εγκατάσταση εξαρτήσεων
pip install -r requirements.txt
```

#### Σε Windows (Command Prompt ή PowerShell):
```cmd
:: 1. Δημιουργία εικονικού περιβάλλοντος
python -m venv venv

:: 2. Ενεργοποίηση
venv\Scripts\activate

:: 3. Εγκατάσταση εξαρτήσεων
pip install -r requirements.txt
```

---

### 2. Εκκίνηση της Εφαρμογής (Streamlit Dashboard)

#### Με εντολή τερματικού:
```bash
streamlit run ui/app.py
```
Η εφαρμογή ανοίγει αυτόματα στον web browser στη διεύθυνση:
👉 **`http://localhost:8501`**

#### Εκτέλεση με 1 κλικ (χωρίς τερματικό):
* **macOS:** Κάντε διπλό κλικ στο αρχείο `run_app.command`.
* **Windows:** Κάντε διπλό κλικ στο αρχείο `run_app.bat`.

---

### 3. Εκτέλεση Αυτοματοποιημένων Ελέγχων (Testing)
Για να επιβεβαιώσετε τη σωστή λειτουργία όλων των υποσυστημάτων:
```bash
python test_system.py
```
Ελέγχονται:
- Συναρτήσεις συμμετοχής (`membership.py`).
- 36 Κανόνες Mamdani και Monte Carlo έλεγχος κάλυψης σε 2000 τυχαίες εισόδους (< 5% gap).
- Σύγκλιση FCM και ευθυγράμμιση Hungarian (`scipy.optimize.linear_sum_assignment`) σε πολλαπλά seeds.
- Κατάλογος 22 προορισμών.
- Μηχανισμός ανάδρασης με απομονωμένο προσωρινό αρχείο.
- Υβριδικός Recommender, όρος `persona_fit` και έλεγχος διαφοροποίησης διακριτών προφίλ.
- Διαδραστικά διαγράμματα Plotly.

## 🖥️ Περιγραφή Λειτουργιών Εφαρμογής

Η εφαρμογή διαθέτει 3 λειτουργίες μέσω του πλαϊνού μενού (Sidebar):

1. **✈️ Σύμβουλος Προτάσεων (Travel Agent Recommender):**
   * Εισαγωγή budget, κλίματος (°C), διάρκειας (ημέρες), ενδιαφερόντων (Πολιτισμός, Περιπέτεια, Χαλάρωση, Νυχτερινή Ζωή) και φίλτρου χώρας.
   * Αυτόματη ταξινόμηση στο κυρίαρχο FCM προφίλ και διάγραμμα ραντάρ (Spider Radar Chart).
   * Προβολή των κορυφαίων 5 προορισμών με ποσοστό καταλληλότητας, ανάλυση κόστους, προτεινόμενο πακέτο γραφείου και **Explainable AI bullet points**.
   * **📄 Εξαγωγή Επίσημης Ταξιδιωτικής Προσφοράς σε PDF (B2B Client Quotation):** Παραγωγή επώνυμης ταξιδιωτικής προσφοράς για τον πελάτη με ανάλυση προφίλ, πακέτα, κόστη και αιτιολόγηση.
   * **🔄 Ανάδραση Χρήστη (Feedback Loop):** Δυνατότητα αξιολόγησης (1-5 αστέρια, αποδοχή/απόρριψη) με δυναμική επαναστάθμιση των μελλοντικών σκορ.

2. **🧠 Ασαφής Μηχανή & FCM (Ακαδημαϊκή Εποπτεία):**
   * Πλήρης οπτικοποίηση όλων των Συναρτήσεων Συμμετοχής με ένδειξη των τρεχουσών εισόδων.
   * Πίνακας των 36 κανόνων IF-THEN με ενεργά firing strengths $\alpha$.
   * Μαθηματικές μετρικές FCM (Partition Coefficient $PC$, Partition Entropy $PE$) και καμπύλη σύγκλισης $J_m$.
   * Πίνακας κεντροειδών των 5 τουριστικών προφίλ σε φυσικές μονάδες (€, °C, ημέρες, 0-10).
   * Πίνακας και analytics του Closed Feedback Loop.

3. **💼 Διαχείριση Καταλόγου & Πακέτων (B2B Inventory):**
   * Πλήρης βάση δεδομένων με **22 προορισμούς** (12 στην Ελλάδα: Σαντορίνη, Χανιά, Ζαγοροχώρια, Αθήνα, Μύκονος, Πήλιο, Μετέωρα, Κέρκυρα, Νάξος, Μάνη/Μονεμβασιά, Καστοριά, Ναύπλιο και 10 διεθνείς: Ρώμη, Παρίσι, Βιέννη, Ζερμάτ, Ρέικιαβικ, Μπαλί, Βαρκελώνη, Άμστερνταμ, Τόκιο, Νέα Υόρκη).
   * Φόρμα προσθήκης νέου προορισμού/πακέτου γραφείου σε πραγματικό χρόνο.
   * Εξαγωγή καταλόγου σε CSV.
